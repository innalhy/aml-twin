# Cloudflare scaffold (not the demo)

The COMP3424 demo deploys on a self-hosted Linux VPS. Follow [`deploy-vps.md`](deploy-vps.md).

`workers/` and the Wrangler files (`workers/api/wrangler.jsonc`, `frontend/wrangler.jsonc`) may remain in the tree as a legacy scaffold. They are not the demo target. Do not deploy this course demo with Wrangler, Cloudflare Workers, or Cloudflare Pages.
