# TwinAML Unity project

Open this folder in **Unity 6000.6.8f1**. Hub matches `ProjectSettings/ProjectVersion.txt` and does not ask for 2022.3.62f1. Do not open the repo root. The 3D rooms are the files in `Assets/Scenes/3D/`. Press Play on `Scn_Branch_Lobby.unity`, or use **TwinAML → Play Branch Lobby**. The topics wall is not a 3D room. Playing it opens the lobby.

The scene map, topic paths, and dashboard fields are in [`../UNITY.md`](../UNITY.md). Topic 3 is the English branch lesson: open `Scn_Boot`, sign in, and start Topic 3. Follow the panel that says Do this next.
