# TwinAML Unity project

Open this folder in Unity 2022.3 LTS. First scene: `Assets/Scenes/Scn_Boot.unity`. Press Play, or use **TwinAML → Play From Boot**.

The scene map, topic paths, and dashboard fields are in [`../UNITY.md`](../UNITY.md). Topic 3 is the English branch lesson: open `Scn_Boot`, sign in, and start Topic 3. Follow the panel that says Do this next.
