# TwinAML Unity project

Open this folder in Unity 2022.3 LTS. The 3D rooms are the files in `Assets/Scenes/3D/`. Press Play on `Scn_Branch_Lobby.unity`, or use **TwinAML → Play Branch Lobby**. The topics wall is not a 3D room. Playing it opens the lobby.

The scene map, topic paths, and dashboard fields are in [`../UNITY.md`](../UNITY.md). Topic 3 is the English branch lesson: open `Scn_Boot`, sign in, and start Topic 3. Follow the panel that says Do this next.
